This record describes the 3.34 release line. The architecture it shows, the module set, module dependencies and native bindings, is the same for every release candidate, GA and patch release of 3.34, so the record names the line, not a single release. It was read from the tree at the commit above. The git tags use a `0.` prefix for tagging purposes only; this SDK publishes under a `3.` prefix.

The comparison below is against the 3.33 line, at tag `v0.33.0`, the release the 3.33 record describes.

## SDK shape

The Navigation SDK for Android splits into a public tree (`mapbox-navigation-android/`, released to customers as separate Maven artifacts) and an internal tree (this repository root) that adds proprietary feature modules on top. Core libraries carry route state, native-engine bridging, trip data and the SDK-wide coroutine dispatchers. UI libraries render maps, camera, and turn-by-turn components on top of Core. Optional libraries add EV routing, ADASIS, road camera, weather, audio, MapGPT, Compose wrappers, the Redux-style coordination layer and the Android Auto virtual display, each consumed selectively by an integrator. Everything bottoms out on bound Mapbox SDKs, each at its 34 release: Maps SDK `v11.34`, Navigation Native `v324.34`, Core Common `v24.34`, Nav SDK C++ `v0.34` (and its full HD artifact at the same version), Search SDK `v2.34`, and Mapbox Java SDK `v7.10.1`, all resolved from `mapbox-navigation-android/gradle/dependencies.gradle`. `compileSdk` and `targetSdk` are 37, `minSdk` is 21.

Seven modules declare a native SDK directly: `navigator` and `base` in the public tree, and `coordination`, `coordination-full-hd`, `datainputs`, `roadcam`, `libnavigation-compose-core` in the internal tree. Every other library reaches native code through them (see `04_native_bridge.md`).

## What changed since the previous release tag

Previous release tag: `v0.33.0` (`3.33.0`, commit `01bb5aa10b377690f8f0c501ef754e4f349351f9`).

| Library | Change | Evidence |
|---|---|---|
| (SDK-wide) | Bound Mapbox SDKs moved from their 33 releases to their 34 releases: Maps SDK `v11.34`, Navigation Native `v324.34`, Core Common `v24.34`, Nav SDK C++ `v0.34`, Search SDK `v2.34`. Mapbox Java SDK stays at `v7.10.1`. No other dependency version changed. | `mapbox-navigation-android/gradle/dependencies.gradle` |
| `android-auto-virtual-display` | New Optional library, published as `com.mapbox.navigationcore:android-auto-virtual-display`. Its experimental `AndroidAutoVirtualDisplayScreen` shows an app-provided Android `View` as an Android Auto screen, and `AndroidAutoVirtualDisplaySessionUtils` forwards car configuration changes to it. It depends on `base` and `navigation`, declares Maps SDK directly, and uses the car minimum SDK level (`carMinSdkVersion`, 23). It declares no native navigation SDK. | `settings.gradle`, `android-auto-virtual-display/build.gradle`, `android-auto-virtual-display/api/current.txt` |
| `android-auto-components` | New `CarRouteLineRenderer(options, carRoutesProvider, onRouteClick)` constructor that reports the route the driver tapped on the car map. The previous two-argument constructor stays. No dependency change outside test configurations. | `android-auto-components/api/current.txt`, `android-auto-components/build.gradle`, `CHANGELOG.md` |
| `coordination` | Route line configuration replaces the `CongestionLevel` map of alternative-route colors with one color per congestion level, and adds inactive-leg colors with `styleInactiveLegsIndependently`. Two file-level Kotlin classes added. | `coordination/api/current.txt` |
| `ev` | The charging station `Location` model adds an optional `lastSuccessfulCharge` date, and its experimental `Location` factory takes it as a new trailing parameter with a `null` default. | `ev/api/current.txt` |
| `ev-ui` | `MapboxEvViewOptions.Builder#withIconFactory` is replaced by `withIconVariantsFactory`, which returns an ordered list of icon variants per station, and `withIconOffsets` sets an offset per variant. | `ev-ui/api/current.txt`, `CHANGELOG.md` |
| (all other libraries) | No `api/current.txt` or `build.gradle` change. The public tree's `settings.gradle` is unchanged. | `git diff v0.33.0 v0.34.0-rc.1` |

## Module notes

`android-auto-virtual-display` is the one new library in this line. It sits beside the other Optional libraries, depends on Core only, and is independent of `android-auto-components`. `ev-ui` and `coordination` changed configuration APIs in a source-incompatible way: `withIconFactory` and the `CongestionLevel` color map are removed. No module record exists for this line.
