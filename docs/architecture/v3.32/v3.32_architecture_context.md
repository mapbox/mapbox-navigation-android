## SDK shape

The Navigation SDK for Android splits into a public tree (`mapbox-navigation-android/`, released to customers as separate Maven artifacts) and an internal tree (this repository root) that adds proprietary feature modules on top. Core libraries carry route state, native-engine bridging, and trip data. UI libraries render maps, camera, and turn-by-turn components on top of Core. Optional libraries add EV routing, ADASIS, road camera, weather, audio, MapGPT, Compose wrappers, and the Redux-style coordination layer, each consumed selectively by an integrator. Everything bottoms out on bound Mapbox SDKs: Maps SDK `v11.32.0`, Navigation Native `v324.32.0`, Core Common `v24.32.0`, Nav SDK C++ `v0.32.0` (and its full HD artifact at the same version), Search SDK `v2.32.0`, and Mapbox Java SDK `v7.10.1`, all resolved from `mapbox-navigation-android/gradle/dependencies.gradle` at this commit. `compileSdk` and `targetSdk` are 37, `minSdk` is 21.

Seven modules declare a native SDK directly: `navigator` and `base` in the public tree, and `coordination`, `coordination-full-hd`, `datainputs`, `roadcam`, `libnavigation-compose-core` in the internal tree. Every other library reaches native code through them (see `04_native_bridge.md`).

## What changed since the previous release tag

Previous release tag: `v0.32.0-rc.1` (`3.32.0-rc.1`, commit `f1c0e606b8321472165384385804838c5b1d7e98`).

| Library | Change | Evidence |
|---|---|---|
| (SDK-wide) | Bound Mapbox SDKs moved from their `32.0-rc.1` releases to `32.0`: Maps SDK `v11.32.0`, Navigation Native `v324.32.0`, Core Common `v24.32.0`, Nav SDK C++ `v0.32.0`, Search SDK `v2.32.0`. | `mapbox-navigation-android/gradle/dependencies.gradle` |
| `copilot` | AndroidX WorkManager, declared by `copilot` only, moved from `2.7.1` to `2.10.5`. This fixes Copilot history uploads in apps minified with R8 full mode. | `mapbox-navigation-android/gradle/dependencies.gradle`, `copilot/build.gradle`, `CHANGELOG.md` |
| `navigation`, `ui-maps`, `coordination` | Implementation changes only, in reroute handling, the navigation viewport data source and the coordination map components. No public API or dependency change. | Source files under each module, `api/current.txt` unchanged |
| (all libraries) | No `api/current.txt`, `build.gradle` or `settings.gradle` change between the two tags, in either tree. | `git diff v0.32.0-rc.1 v0.32.0` |
