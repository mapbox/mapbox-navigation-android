## SDK shape

The Navigation SDK for Android splits into a public tree (`mapbox-navigation-android/`, released to customers as separate Maven artifacts) and an internal tree (this repository root) that adds proprietary feature modules on top. Core libraries carry route state, native-engine bridging, and trip data. UI libraries render maps, camera, and turn-by-turn components on top of Core. Optional libraries add EV routing, ADASIS, road camera, weather, audio, MapGPT, Compose wrappers, and the Redux-style coordination layer, each consumed selectively by an integrator. Everything bottoms out on bound Mapbox SDKs: Maps SDK `v11.32.0-rc.1`, Navigation Native `v324.32.0-rc.1`, Core Common `v24.32.0-rc.1`, Nav SDK C++ `v0.32.0-rc.1` (and its full HD artifact at the same version), Search SDK `v2.32.0-rc.1`, and Mapbox Java SDK `v7.10.1`, all resolved from `mapbox-navigation-android/gradle/dependencies.gradle` at this commit. `compileSdk`/`targetSdk` moved from 36 to 37 at this tag.

Seven modules declare a native SDK directly: `navigator` and `base` in the public tree, and `coordination`, `coordination-full-hd`, `datainputs`, `roadcam`, `libnavigation-compose-core` in the internal tree. Every other library reaches native code through them (see `04_native_bridge.md`).

## What changed since the previous release tag

This is the first architecture record. Previous release tag: `v0.31.1` (`3.31.1`, commit `9f8d6e562aaeb0a36c53093fdab5c402471dc56b`).

| Library | Change | Evidence |
|---|---|---|
| `androidauto` | Added `CarRouteLineRendererOptions` (and its `Builder`) as a new optional constructor parameter on `CarRouteLineRenderer`, letting an integrator supply custom route-line, route-arrow, and their options providers for the Android Auto surface. | `androidauto/api/current.txt` |
| `androidauto` | Added `MapboxScreen.NAVIGATION` and `MapboxNavigationScreenFactory`, consolidating what were three separate screen states (`ACTIVE_GUIDANCE`, `FREE_DRIVE`, `ROUTE_PREVIEW`) and their factories, which are now `@Deprecated` in favor of the single `NAVIGATION` state. | `androidauto/api/current.txt` |
| `androidauto` | Declares `androidx.car.app` directly, at a newer version than the one the Maps Android Auto extension pulls in. | `androidauto/build.gradle` |
| (all other libraries) | No `api/current.txt`, `build.gradle` or `settings.gradle` change between the two tags, in either tree. | `git diff v0.31.1 v0.32.0-rc.1` |
| (SDK-wide) | `compileSdk`/`targetSdk` bumped 36 to 37. | `mapbox-navigation-android/gradle/dependencies.gradle`, `CHANGELOG.md` |
