## SDK shape

The Navigation SDK for Android splits into a public tree (`mapbox-navigation-android/`, released to customers as separate Maven artifacts) and an internal tree (this repository root) that adds proprietary feature modules on top. Core libraries carry route state, native-engine bridging, trip data and the SDK-wide coroutine dispatchers. UI libraries render maps, camera, and turn-by-turn components on top of Core. Optional libraries add EV routing, ADASIS, road camera, weather, audio, MapGPT, Compose wrappers, the Redux-style coordination layer and the Android Auto virtual display, each consumed selectively by an integrator. Everything bottoms out on bound Mapbox SDKs, each at its 36 release: Maps SDK `v11.36`, Navigation Native `v324.36`, Core Common `v24.36`, Nav SDK C++ `v0.36` (and its full HD artifact at the same version), Search SDK `v2.36`, and Mapbox Java SDK `v7.10.1`, all resolved from `mapbox-navigation-android/gradle/dependencies.gradle`. `compileSdk` and `targetSdk` are 37, `minSdk` is 21.

Seven modules declare a native SDK directly: `navigator` and `base` in the public tree, and `coordination`, `coordination-full-hd`, `datainputs`, `roadcam`, `libnavigation-compose-core` in the internal tree. Every other library reaches native code through them (see `04_native_bridge.md`).

## What changed since the previous release line

Previous release line: 3.35 (commit `44a330e2222d823142c1b46e2ee73f0ff36e0c4a`, the commit the 3.35 record describes).

| Library | Change | Evidence |
|---|---|---|
| (SDK-wide) | Bound Mapbox SDKs moved from their 35 releases to their 36 releases: Maps SDK `v11.36`, Navigation Native `v324.36`, Core Common `v24.36`, Nav SDK C++ `v0.36`, Search SDK `v2.36`. Mapbox Java SDK stays at `v7.10.1`. `compileSdk` and `targetSdk` stay at 37. | `mapbox-navigation-android/gradle/dependencies.gradle` |
| `android-auto-components` | Experimental favorites action: `buildFavoritesAction` and a `frameFavoritesOnMap` option on the car options. The `FAVORITES` screen key and `FavoritesScreenFactory` are deprecated. | `android-auto-components/api/current.txt` |
| `coordination` | Route line border congestion colors: `RouteBorderCongestionColors`, set per route, alternative route and inactive leg, behind `enableBorderCongestionColors` in `RouteLineConfig`. `CalloutsConfig` adds `avoidLayerIds`. The navigation and route preview presenter states expose `pinsInfo` (`PinsInfo`, the pin layer IDs), and `NavigationPresenterState` adds `possibleNavDefinitionQuality`. | `coordination/api/current.txt` |
| `ev-rangemap` | `EvRangeMapFailureType` adds `NO_RANGE`. `MapboxEvRangeMapInvalidationEvent` and `MapboxEvRangeMapPresenter.invalidationEvents` are deprecated. `MapboxEvRangeMapPresenter` and its factory are marked `@UiThread`. | `ev-rangemap/api/current.txt` |
| (all other libraries) | No `api/current.txt` change and no non-test `build.gradle` change. `coordination` and `ev-rangemap` added test dependencies only. Neither `settings.gradle` changed. | `git diff 44a330e2222d cabed8953710` |
