## SDK shape

The Navigation SDK for Android splits into a public tree (`mapbox-navigation-android/`, released to customers as separate Maven artifacts) and an internal tree (this repository root) that adds proprietary feature modules on top. Core libraries carry route state, native-engine bridging, trip data and the SDK-wide coroutine dispatchers. UI libraries render maps, camera, and turn-by-turn components on top of Core. Optional libraries add EV routing, ADASIS, road camera, weather, audio, MapGPT, Compose wrappers, the Redux-style coordination layer and the Android Auto virtual display, each consumed selectively by an integrator. Everything bottoms out on bound Mapbox SDKs, each at its 35 release: Maps SDK `v11.35`, Navigation Native `v324.35`, Core Common `v24.35`, Nav SDK C++ `v0.35` (and its full HD artifact at the same version), Search SDK `v2.35`, and Mapbox Java SDK `v7.10.1`, all resolved from `mapbox-navigation-android/gradle/dependencies.gradle`. `compileSdk` and `targetSdk` are 37, `minSdk` is 21.

Seven modules declare a native SDK directly: `navigator` and `base` in the public tree, and `coordination`, `coordination-full-hd`, `datainputs`, `roadcam`, `libnavigation-compose-core` in the internal tree. Every other library reaches native code through them (see `04_native_bridge.md`).

## What changed since the previous release line

Previous release line: 3.34 (commit `08a6b5f56dfcbfec0f7b898d3b32b093d81acd7c`, the commit the 3.34 record describes).

| Library | Change | Evidence |
|---|---|---|
| (SDK-wide) | Bound Mapbox SDKs moved from their 34 releases to their 35 releases: Maps SDK `v11.35`, Navigation Native `v324.35`, Core Common `v24.35`, Nav SDK C++ `v0.35`, Search SDK `v2.35`. Mapbox Java SDK stays at `v7.10.1`. The Mapbox Gradle build plugins (SDK registry, access token, native download) moved to newer versions. Build tooling only, with no effect on the module graph. | `mapbox-navigation-android/gradle/dependencies.gradle` |
| `android-auto-components` | Experimental car settings API: `CarSettingsTemplateProvider` and `CarSettingsMode` (free drive, route preview, active guidance), a `settingsTemplateProvider` option on the car options, and `buildSettingsAction` helpers. `CarContextExtensions.supportsUnifiedNavigation` added. `SettingsScreenFactory`, the `SETTINGS` screen key and `prepareExperimentalRoutePreviewScreen` are deprecated. | `android-auto-components/api/current.txt` |
| `coordination` | `NavigationPresenter` exposes `customArrows`, a `NavigationPresenterCustomArrows` interface to add, query and remove custom route line arrows, with `RouteLineCustomArrow` and its presentation, change and error types. `RouteLineConfig` adds `maneuverArrowCount` and `maneuverArrowsHideOverlappingSymbols`. The deprecated `framingStrategy` is removed from the following-camera configuration classes. | `coordination/api/current.txt` |
| (all other libraries) | No `api/current.txt` or `build.gradle` change. Neither `settings.gradle` changed. | `git diff 08a6b5f56dfc 44a330e2222d` |

## Module notes

`coordination` removed the deprecated `framingStrategy` from its following-camera configuration, a source-incompatible change for code that still set it. `android-auto-components` added a settings API and deprecated the previous settings screen. No module record exists for this line.
