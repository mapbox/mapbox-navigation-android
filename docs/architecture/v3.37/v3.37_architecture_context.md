## SDK shape

The Navigation SDK for Android splits into a public tree (`mapbox-navigation-android/`, released to customers as separate Maven artifacts) and an internal tree (this repository root) that adds proprietary feature modules on top. Core libraries carry route state, native-engine bridging, trip data and the SDK-wide coroutine dispatchers. UI libraries render maps, camera, and turn-by-turn components on top of Core. Optional libraries add EV routing, ADASIS, road camera, weather, audio, MapGPT, Compose wrappers, the Redux-style coordination layer and the Android Auto virtual display, each consumed selectively by an integrator. Everything bottoms out on bound Mapbox SDKs, each at its 37 release: Maps SDK `11.37.0`, Navigation Native `324.37.0`, Core Common `24.37.0`, Nav SDK C++ `0.37.0` (and its full HD artifact at the same version), Search SDK `2.37.0`, and Mapbox Java SDK `7.10.1`, all resolved from `mapbox-navigation-android/gradle/dependencies.gradle`. `compileSdk` and `targetSdk` are 37, `minSdk` is 21.

Seven modules declare a native SDK directly: `navigator` and `base` in the public tree, and `coordination`, `coordination-full-hd`, `datainputs`, `roadcam`, `libnavigation-compose-core` in the internal tree. Every other library reaches native code through them (see `04_native_bridge.md`).

## What changed since the previous release tag

Previous release tag: v0.36.0-rc.1 (SDK 3.36.0-rc.1, commit c341f58751de936d246726a6b4b6df60bbeca43c).

| Library | Change | Evidence |
|---|---|---|
| (SDK-wide) | Bound Mapbox SDKs moved from their `36.0-rc.1` lines to their 37 line: Maps SDK `11.37.0`, Navigation Native `324.37.0`, Core Common `24.37.0`, Nav SDK C++ `0.37.0`, Search SDK `2.37.0`. Mapbox Java SDK stays at `7.10.1`. `compileSdk` and `targetSdk` stay at 37. | `mapbox-navigation-android/gradle/dependencies.gradle` |
| `base` | `RouterFailureType.ROUTER_RECREATION_ERROR` is deprecated, on both the annotation companion and the `RouterFailureType.Companion` class. | `base/api/current.txt` |
| `navigation` | The `CacheHandleWrapperKt` class is removed from the tracked surface of `com.mapbox.navigation.core.navigator`. It had no members. | `navigation/api/current.txt` |
| `coordination` | `LaneLevelGuidanceTheme` gains optional `activeRouteBlur`, `activeRouteBorderBlur`, `alternativeRouteBlur` and `alternativeRouteBorderBlur` values, a `displayTrafficOnCarpet` flag, a `displaySoftGradientForTraffic` flag and a `softGradientTransitionLength` value, each with a getter and a property. `LaneLevelGuidanceThemeUpdateBuilder` gains a matching setter method for each. The `build.gradle` files of `coordination` and `coordination-full-hd` change only in how the shared instrumentation-test helper sources are wired: `coordination` adds a `src/sharedAndroidTest/java` source directory and `coordination-full-hd` reads it. Module dependencies are unchanged. | `coordination/api/current.txt`, `coordination/build.gradle`, `coordination-full-hd/build.gradle` |
| `ev-ui` | `MapboxEvViewOptions` gains an optional `alwaysShownStations` list, with a getter, a property and a `withAlwaysShownStations` builder method. The new `AlwaysShownStation` class (`id`, `coordinate`) carries each entry and is marked `@ExperimentalPreviewMapboxEvAPI`. | `ev-ui/api/current.txt` |
| `datainputs` | `OrientationData` gains an optional `yawAccuracy` value: a new constructor parameter that defaults to `null`, with a `getYawAccuracy()` getter and a `yawAccuracy` property. Existing calls keep compiling. | `datainputs/api/current.txt` |
| (all other libraries) | No `api/current.txt` change and no `build.gradle` change in a library module, other than the rows above. The module lists in both `settings.gradle` files are unchanged. The root `settings.gradle` changed only in how the from-source build resolves the NDK major version. The only `build.gradle` changes are in `instrumentation-tests` and `instrumentation-tests-internal`, which are out of scope. | `diff -u` of the files at `v0.36.0-rc.1` and at this commit |

## Module notes

`base` deprecated `ROUTER_RECREATION_ERROR` in `RouterFailureType`. `coordination` added blur values, a `displayTrafficOnCarpet` flag and soft-gradient traffic options to `LaneLevelGuidanceTheme` and its update builder. `datainputs` added `yawAccuracy` to `OrientationData`. `ev-ui` added `alwaysShownStations` to `MapboxEvViewOptions`. `navigation` dropped the empty `CacheHandleWrapperKt` class from its tracked API. No module was added or removed. No module record exists for this line.
