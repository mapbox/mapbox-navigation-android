- Fixed a memory leak in the route line component installed with `ComponentInstaller.routeLine`: it now removes its map click listener when detached, so a component recreated on the same `MapView` no longer keeps the previous instances, together with their `MapboxRouteLineApi` and `MapboxRouteLineView`, alive.
- Fixed a memory leak where a `MapboxRouteLineApi` that was dropped without calling `cancel()` stayed in memory, together with its routes, for the rest of the process. Calling `cancel()` when the instance is no longer used is still recommended.
- `MapboxRouteLineView.cancel()` now stops waiting for the map: a `RoutesRenderedCallback` that is still waiting for the map to finish rendering or clearing routes is invoked right away, with the routes the map has not rendered or cleared yet reported as cancelled.
