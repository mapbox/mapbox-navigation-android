- Android Auto: on Car API 7 and newer, the unified navigation screen shows settings alongside the map in free drive, route preview, and active guidance. Back restores navigation without clearing the route preview or stopping guidance. Settings also close on navigation-mode changes or when the screen pauses.
- Android Auto: added experimental `CarSettingsTemplateProvider`, `CarSettingsMode`, and the `MapboxCarOptions` / `MapboxCarOptions.Customization` `settingsTemplateProvider` properties for custom inline settings content, and `buildSettingsAction` for default or custom settings icons and titles.
- Android Auto: deprecated `MapboxScreen.SETTINGS` and `SettingsScreenFactory`. Use inline settings on `MapboxScreen.NAVIGATION` instead; dedicated legacy settings screens remain available for compatibility.
- Android Auto: the default unified route-preview and active-guidance action strips now include settings. Active guidance uses all four host action slots (settings, feedback, audio guidance, and Stop), so providers extending `super.getActiveGuidance(screen)` must replace an action rather than append a fifth one, which would cause the host template builder to throw `IllegalArgumentException`. The settings action is omitted while inline settings are open; custom strips and legacy dedicated preview and guidance defaults are otherwise unchanged.
